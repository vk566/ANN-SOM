"# ANN-SOM" 
🌼 Self-Organizing Map (SOM) on the Iris Dataset
Unsupervised Machine Learning | Neural Network Topology Preservation | Data Visualization

This repository contains a complete implementation of a Self-Organizing Map (SOM) applied to the Iris dataset, using the MiniSom library.
The goal of this project is to explore how SOMs can cluster and visualize high-dimensional data while revealing hidden structure.
